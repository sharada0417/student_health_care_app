# Student Health Care (ICAE - 2)

**Student Health Care** is a mobile application built as part of the ICAE-2 course. The app allows students to manage their health data, including viewing their BMI, health records, and profile information. It also includes functionality for logging in and viewing various health-related details.

## Features

- **Home Page**: A landing page that provides an overview of the app.
- **BMI Page**: A page that calculates and displays the student's Body Mass Index (BMI) based on their height and weight.
- **Health Page**: Displays detailed health information, including last checkup date, heart rate, weight, height, and more.
- **Profile Page**: Displays the student's health profile, which includes various health records and medical conditions.

## Installation

To set up the project locally, follow the steps below:

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/StudentHealthCare.git
    ```

2. Navigate into the project directory:
    ```bash
    cd StudentHealthCare
    ```

3. Install the dependencies:
    ```bash
    npm install
    ```

4. Run the app in development mode using Expo:
    ```bash
    expo start
    ```

This will launch the app in the Expo Developer Tools, where you can scan the QR code to run the app on your mobile device or use an Android/iOS emulator.

## Dependencies

The following libraries are used in the **Student Health Care** app:

- **Expo**: A framework for building React Native applications.
    ```bash
    npm install expo
    ```

- **React Navigation**: A library for handling navigation in React Native.
    ```bash
    npm install @react-navigation/native @react-navigation/native-stack
    ```

- **React Native Paper**: Provides Material Design components for the UI.
    ```bash
    npm install react-native-paper
    ```

- **React Native Safe Area Context**: Ensures content is not obscured by the device’s status bar or notch.
    ```bash
    npm install react-native-safe-area-context
    ```

- **React Native Vector Icons**: Provides customizable vector icons.
    ```bash
    npm install react-native-vector-icons
    ```

- **Async Storage**: Used for persistent storage in the app.
    ```bash
    npm install @react-native-async-storage/async-storage
    ```
